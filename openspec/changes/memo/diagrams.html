memo 业务流程图与状态流转图

根据最新设计拆成三张图：业务流程图、配置生命周期状态图、单次归档生命周期状态图。配置偏好会持久化，运行时检查和单次归档状态不会被当成永久配置。

业务流程图

从安装到初始化，再到 $memo 写入、修改、确认、放弃或归档。

配置生命周期状态图

安装、初始化和配置 ready 是产品配置状态；memo info / memo doctor 是旁路动作，不是主状态。

单次归档生命周期状态图

每次 $memo 调用产生一个归档会话。确认前只更新同一份 draft；确认后才 commit/push；放弃时清理本次 draft 和附件。

提交时机

只有用户确认归档后才 commit。确认前的 draft 不进入 Git 历史，修改不会制造多次草稿提交。

放弃归档

第一版只处理新建笔记：删除本次会话创建的 draft 文件和附件，不 commit、不 push。

同一文件修改

用户要求修改时写回同一份 draft Markdown 文件，并复用同一个附件目录。

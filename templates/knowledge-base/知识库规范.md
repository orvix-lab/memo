## 归档规则

长期知识笔记必须使用完整 Frontmatter，标题与一级标题一致，包含 3 至 8 个具体标签、非空摘要以及“结论、适用范围、核心内容、关键检索词、关联文档、来源与验证”章节。

优先归档需求与方案到 `30-方案与需求`，单一项目资料到 `20-项目`，跨服务业务知识到 `10-业务领域`，通用工程经验到 `40-技术沉淀`。无法分类时使用 `90-收件箱` 和 `待确认` 状态；不要为单篇资料创建顶级目录。

归档前检索标题、项目和核心术语。已有主笔记时优先更新或关联；大范围改写或移动前要求确认。新增、移动、归档或删除受管理笔记后同步更新 README 清单。历史笔记按需渐进治理，不批量移动或重命名。
